## Redlining in Los Angeles County, California

This repository houses the data and script visualizing the 1930’s Home Owners’ Loan Corporation (HOLC) redlining of neighborhoods in Los Angeles County, and associated rates of environmental injustice.

![](https://eds-223-geospatial.github.io/assignments/images/holc-la.png)

[EDS 223 Assignment #2: Exploring patterns of environmental justice](https://eds-223-geospatial.github.io/assignments/HW2V2.html#rubric-specifications)

Contents

| Folder | Housing | Description |
|------------------|------------------|-----------------------------------|
| data/ejscreen/ | EJScreen Website | [Environmental Justice Screening and Mapping Tool (Version 3.2022.3).](https://pedp-ejscreen.azurewebsites.net/) |
| data/mapping-inequality/ | Mapping Inequality Project Website | Digitized maps and information from the HOLC created by the [Digital Scholarship Lab](https://dsl.richmond.edu/) at the University of Richmond |
| data/SWIRTS_LA/ | Transportation Information Mapping System (TIMS) clearing house | Data on collision scenes gathered by UC Berkeley SafeTREC |
| HW2.qmd | This repo | R script to filter, aggregate, and visualize environmental injustice in LA |
